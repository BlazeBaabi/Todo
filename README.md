# Todo Cloudbased
A quick, simple, and private to-do list manager designed to help you keep your projects organized without connecting to the cloud.

## Features Overview
This local application allows users to manage multiple collections of tasks efficiently.

### Getting Started (Setup)
1. **Extraction:** Unzip the provided folder package.
2. **Execution:** Run the `main.pyw` file. (Note: This is designed for easy and direct execution).

### Collections Management
Collections act as containers for your related projects (e.g., "Work Project X," "Personal Goals").

*   **View All:** Click the **"Default"** collection name at the top of the screen to view all available groups.
*   **Create New:** Click the **"+ New"** button to instantly create a blank, labeled collection.
*   **Rename:** Select any collection and click **"Rename"** to change its title or focus area.

### Task Management
This is where you add, modify, and complete your actual tasks.

#### Adding Tasks
1. Click the **"Add"** button at the bottom of the screen.
2. Enter a Title (and optionally a Description/Priority).
3. Click **"Save"**. The task is now active within the selected collection.

#### Editing & Completing Tasks
*   **Edit:** Select any existing task and click **"Edit"** to modify its title, description, or priority level without losing its place in your list.
*   **Complete:** Click **"Complete"** on a task when it's finished! Completed tasks are visually marked (e.g., greyed out) for easy distinction.

#### Deleting Tasks
*   Select any task and click **"Remove"** to permanently delete it from the list. *(Include a warning here, e.g., "This action cannot be undone.")*
